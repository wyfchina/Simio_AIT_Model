## 目标
建立统一的统计框架，覆盖案例要求的 5 类指标，外加报告需要的 3 个辅助指标。完工驱动线和脉动线使用同样的口径，保证可比（原则 10.6）。

## 条件
- 依赖：#6（脉动线的专属指标在 #9 中接入）

## 指标定义与实现

| 指标 | 定义 | 实现 |
|---|---|---|
| **周期时间 CT** | 相邻两架飞机**完工**的时间间隔（日历日）。第 1 架完工前的爬坡期不计入 | Sink 进入时：如果 LastDoneTime > 0，就把 `TimeNow − LastDoneTime` 记入 Tly_CT（单位：天），然后更新 LastDoneTime |
| **批次完成时间** | 最后一架（第 75 或 100 架）完工的时刻（日历日） | 完工数达到 Prop_NumPlanes 时，把 TimeNow 记入输出统计 Out_Makespan，并结束运行（Run Ending 或 End Run 步骤） |
| **WIP** | 已进入工位 1、尚未完工的飞机数，不含线外投放池；脉动线还包括线外补工区 | 状态 St_WIP：进入工位 1 时 +1，完工时 −1。按原则 1，先记积分再增减。用 TimeWeighted Statistic 统计时间平均值，另记最大值 |
| **人力利用率** | 机械师忙时 ÷ 上班可用工时 | 按工位汇总单人资源的 ScheduledUtilization；同时给出全线平均。说明分母只算上班时间 |
| **阻塞 / 饥饿** | 各工位处于 Blocked / Starved 状态的时间占比 | 用 Server 的 ResourceState 状态统计。分母取工作时间（扣除 OffShift），日历时间口径另附一份 |
| 辅助：单机流程时间 | 每架飞机从进入工位 1 到完工的时间 | Tly_FlowTime；用 Little 定律校验 WIP ≈ 产出率 × 流程时间 |
| 辅助：工位驻留时间分解 | 每个工位内的加工时间、阻塞时间、缓冲等待时间 | 用进出时间戳计算 |
| 辅助：traveled work | 见 #9 | 仅脉动线 |

## 实施步骤

- [ ] 在 Facility 中放 Status Pie（每工位一个）和 WIP 的 Time Plot，中文标题，标注单位

- [ ] 守恒检查：投放数 = 完工数 + 结束时的 WIP；运行结束时 WIP = 0
