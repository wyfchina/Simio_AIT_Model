## 目标
实现题目要求的**完工驱动线**（Initial Model）：5 个工位串联，用 Task Sequence 执行 Tbl_Tasks 中本工位的工序，只有本工位全部工序完成，飞机才能离开（没有 traveled work）。工位容量和缓冲位都参数化，用一个模型覆盖案例中的 4 种情形。

## 条件
- 依赖：#4（S1–S4 已通过或已确定备选方案）、#5

## 设计
- 物理工位：`Srv_L1_C1` … `Srv_L1_C5`
  - Process Type = Task Sequence；Processing Tasks 绑定 Tbl_Tasks（按 #4 S1 的方式过滤）
  - Sequence Number = Tbl_Tasks.Seq
  - 资源需求 = Tbl_Cells/Tbl_Stations 中的 MechList，人数取 Tbl_Tasks.Mechanics
  - Initial Capacity = Prop_CellCap；工位日程按 #4 S3 的结论设置
- 缓冲：**工位 k 与 k+1 之间的缓冲 = 工位 k+1 的 InputBuffer = Prop_Buffer**
  - 工位 1 的 InputBuffer 固定为 0，线外投放池不算物理空间
  - 所有工位的 OutputBuffer = 0，这样做完的飞机被下游堵住时留在工位上，状态为 Blocked
- 投放：投放池（Source 的输出缓冲，或一个专用的 Server/Station）中的飞机在工位 1 能接收时立即进入
- 连接：使用零行程时间的 Connector（原则 7.3），因为题目中没有移动时间
- 进入工位时：Entered 加载过程 `Prc_进入工位` 负责设置行引用并登记时间戳（中文 Step 名，赋值按功能集中，原则 1、2）

| 案例情形 | Prop_CellCap | Prop_Buffer |
|---|---|---|
| ① 零缓冲 | 1 | 0 |
| ② 工位间 1 个位置 | 1 | 1 |
| ③ 无限缓冲 | 1 | ∞ |
| ④ 容量 2、零缓冲 | 2 | 0 |
