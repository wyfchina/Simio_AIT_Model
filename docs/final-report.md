# Simio Aerospace AIT 模型案例报告

## 1. 结论摘要

推荐把 **Flow、容量 2、相邻支援 B2、S2 班次**作为当前模型中的候选方案：在 `Exp_D_Shift` 的 V0.8 口径下，A4+B2 的 S2 平均 CT 为 3.3281 日、Makespan 为 265.5251 日、加权付薪人时为 2250.35/架。S3 可进一步降低 CT，但加权人时升至 2559.95/架；S1 的 CT 为 3.3967 日、加权人时为 2486.23/架。该推荐只适用于当前快照和实验假设，不代表实际工厂投资最优。

## 2. 现状诊断（#9）

Pulse 基准按 4 日节拍投放，飞机位置和工作订单责任工位解耦。75 架、20 次重复的 `Pulse75_S0` 生成并完成 375 张工作订单，守恒差额为 0；平均实际 Makespan 为 346.3431 日。名义位置离线时间是 316 日，最后订单还会在 `Srv_P_Hold` 补工，因此名义离线不等于真实完工。

任务级结果显示平均 45.6249% 的任务在责任工位截止时间后完成。完成时带走深度 0/1/2/3/Hold 的平均订单数为 75.00/184.50/46.35/8.75/60.40，说明 traveled work 是由节拍与工序关键路径不匹配造成的结构性结果。

## 3. 完工驱动容量与缓冲（#10）

V0.5 的 `Exp_A_Buffer` 中，A1（容量 1、缓冲 0）平均 CT 9.4894 日、Makespan 731.6626 日；A2 增加有限缓冲后产出不变而 WIP 上升；A3 无限缓冲的平均 WIP 约 12.95 架、平均最大 WIP 约 24 架，仍未改善 CT 或 Makespan。A4（容量 2、缓冲 0）把 CT 降至 4.8608 日、Makespan 降至 389.4457 日。容量释放并行能力比单纯增加缓冲更有效。

## 4. 人力灵活性（#11）

Task Sequence 原生资源表按 B0–B4 选择名单和人数，`Must Simultaneously Seize=True`。C1 原生验收证实包含 3 人任务的同时取人和释放。V0.6 `Exp_B_Labor` 结果表记录各策略的 CT、Makespan、利用率和人员配置；灵活用工的价值主要在多架竞争和容量受限时体现，单架或资源不构成瓶颈时收益很小。

## 5. SA103 与分流（#12）

`Exp_C_SA103` 包含单线/双线、SA103 配额和分流策略的正式场景。100 架场景逐次得到 SA101/SA102/SA103 = 45/30/25，飞机完成数、工作订单守恒和 D1 非对称负荷分流均通过。3.5 日节拍与 316 日批次目标是不同问题：按 75 架、4 日节拍为 `(75+4)×4=316` 日；按 100 架、3.5 日节拍为 364 日，不能混作同一验收目标。

## 6. 班次与成本（#13）

`Exp_D_Shift` 有 20 个场景、每场景 10 次重复。以 A4+B2、S0 为基准，S1 的 CT 降低约 28.46%、加权人时增加约 14.16%；S2 的 CT 降低约 29.91%、加权人时仅增加约 3.33%；S3 的 CT 降低约 50.11%、加权人时增加约 17.55%。这些结果没有计入招聘、培训和编制成本，不能单独推出总投资最优方案。

## 8. 假设与局限

模型不包含物料搬运、走动距离、质量返工、招聘培训、设备故障和真实工资金额。BASE 与 Flow 结果必须按模型版本边界使用；V0.5 的 BASE 不能与 V0.6 之后的 BASE 直接混比。V5 的工作小时是按平均日历 CT 和 S0 排班比例折算的近似值，不是逐架区间累计。
