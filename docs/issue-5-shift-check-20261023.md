# Issue #5 工作日程核查（2026-10-23）

## 当前设置

模型属性 `Wkr_InitialWorkSchedule` 为 `Schedule` 类型，当前默认值为 `Sch_S0`。10 个 Worker 群体的 `Initial Work Schedule` 均引用该模型属性；实验场景在运行初始化时选择 `Sch_S0` 至 `Sch_S3`。`Prop_Shift` 保存班次编号，但不直接映射为 Worker 正在使用的日程，也不代表仿真运行中的动态换班。

周计划的工作日范围为：`Sch_S0` 和 `Sch_S2` 按周一至周五排班；`Sch_S1` 和 `Sch_S3` 按七天排班。因此“周五 22:00 至周一 06:00 为 0 容量”只适用于工作日计划 S0/S2；S1/S3 的周末排班是设计要求，不能按整段为零判断。

## 原生实验工时验收

`Issue5_Validation` 每个班次场景运行 30 次，每次 336 小时（两周）。Simio 返回 Worker 群体 `[Population] UnitsScheduled` 平均值。每个群体有 8 名 Worker，故按下式换算每人每周可用工时：

`每人每周工时 = 群体平均排班人数 × 336 / 8 / 2`

| 场景 | 日程 | 群体平均排班人数 | 折算工时 | 目标 | 结果 |
|---|---|---:|---:|---:|---|
| `Scenario1`（S0） | `Sch_S0` | 3.5714286 | 75.0 小时/人/周 | 75 | 通过 |
| `S1_75` | `Sch_S1` | 5.0000000 | 105.0 小时/人/周 | 105 | 通过 |
| `S2_75` | `Sch_S2` | 5.1190476 | 107.5 小时/人/周 | 107.5 | 通过 |
| `S3_75` | `Sch_S3` | 7.1666667 | 150.5 小时/人/周 | 150.5 | 通过 |

四个场景各 30 次重复全部完成，无实验错误；静态模型诊断为 0 错误。排班工时来自仿真结果，不是仅凭日程名称或属性值推算。

## 结论边界

- `Wkr_InitialWorkSchedule` 是当前场景/重复运行的日程选择入口；单独修改 `Prop_Shift` 不会自动执行 `SetWorkSchedule`。
- 工时统计验收了每周排班总量。工作日/七天日历范围按当前四套周计划定义解释；S1/S3 周末上班属于预期设置。
- 先前按具体 Worker 引用设置 `SetWorkSchedule` 的失败属于已弃用方案；当前不使用该失败流程，`OnRunInitialized` 保留 `RemainSA103=Prop_NumSA103` 初始化。
